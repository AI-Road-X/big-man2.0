# 租车公司模拟游戏 - 产品需求文档 (PRD)

## 1. 产品概述

一款仿《航空大亨4》风格的3D租车公司模拟经营游戏。玩家扮演租车公司老板，在俯视的城市地图上管理多个租赁网点、车队和资金。游戏采用全3D渲染，通过直观的方式展示公司运营状态。

**核心价值**：让玩家体验创业经营的乐趣，从一个小公司逐步发展成为租车业巨头。

**目标用户**：喜欢模拟经营类游戏的玩家，尤其是《航空大亨》系列爱好者。

---

## 2. 核心功能

### 2.1 3D场景展示

| 功能 | 描述 |
|------|------|
| 全屏3D场景 | 基于Three.js的WebGL渲染 |
| 俯视视角 | 初始相机位于场景上方，可旋转缩放 |
| 交互控制 | 鼠标拖拽旋转、滚轮缩放 |
| 地面效果 | 城市网格或简约地面纹理 |

### 2.2 租赁网点系统

| 功能 | 描述 |
|------|------|
| 网点建模 | 立方体几何体，代表办公楼/门店 |
| 随机分布 | 5个网点随机位置生成 |
| 标签显示 | 网点名称 (网点 A, B, C, D, E) |
| 颜色区分 | 不同网点使用不同颜色 |

### 2.3 控制面板

| 功能 | 描述 |
|------|------|
| 位置 | 右下角固定显示 |
| 样式 | 白色半透明卡片，圆角设计 |
| 显示内容 | 当前月份、公司现金、总车队数量 |
| 数据初始化 | 现金100万、车队0辆、月份1月 |

### 2.4 游戏状态管理

| 状态 | 初始值 | 说明 |
|------|--------|------|
| 公司现金 | ¥1,000,000 | 初始资金100万 |
| 总车队数量 | 0 | 暂无车辆 |
| 当前月份 | 1 | 从1月开始 |

## 3. 用户界面设计

### 3.1 视觉风格

- **整体风格**：现代扁平化 + 轻量3D效果
- **配色方案**：
  - 主色：深蓝 #1a1a2e (夜空感)
  - 次要色：浅灰 #f0f0f0 (面板背景)
  - 强调色：橙色 #ff6b35 (数据高亮)
  - 文字色：深灰 #333333
- **字体**：无衬线字体，清晰易读
- **面板风格**：毛玻璃效果 (backdrop-filter)

### 3.2 3D场景设计

- **地面**：深色网格平面，营造城市感
- **网点立方体**：尺寸约 10x10x10 单位，带轻微发光边缘
- **标签**：3D精灵文字，悬浮于立方体上方
- **光照**：柔和环境光 + 方向光

### 3.3 响应式处理

- 3D场景自适应窗口大小
- 控制面板固定尺寸，始终可见
- 支持不同屏幕比例

## 4. 技术实现

### 4.1 技术栈

| 技术 | 版本/说明 |
|------|-----------|
| Three.js | r150+ (CDN引入) |
| OrbitControls | Three.js插件 |
| Canvas 2D | 文字渲染 |
| HTML5 | 单文件结构 |
| CSS3 | 面板样式、动画 |

### 4.2 项目结构

```
/workspace
└── index.html (单文件，包含所有代码)
```

### 4.3 核心实现

1. **Three.js场景初始化**
   - 创建场景、相机、渲染器
   - 配置OrbitControls
   - 添加地面网格

2. **网点生成**
   - 循环5次生成立方体
   - 随机位置 (x: -50~50, z: -50~50)
   - 避免重叠

3. **3D文字标签**
   - 使用Canvas绘制文字
   - 创建Sprite材质
   - 悬浮于立方体上方

4. **控制面板**
   - HTML/CSS绝对定位
   - 毛玻璃效果
   - 动态数据绑定
